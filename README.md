# Clothing Ecommerce Engine

Standalone reusable ecommerce engine for clothing stores.

## Architecture
- Next.js / React storefront
- Supabase backend
- GitHub source control
- Multi-brand / multi-tenant foundation

## Core modules
- Storefront
- Admin dashboard
- Products, categories, variants, inventory
- Customers
- Orders and order items
- Coupons
- Store settings and branding

This repository is completely separate from Botera.
